GPT-3는 Instruction, 즉 명령을 듣는다기보단 패턴을 완성하는 느낌이었기때문에 task를 풀게할때도 원하는 방향으로 문장을 자동생성하도록 패턴을 만들어줬어야했음.
Instruction 은 이런식으로 사람에게 묻듯이 task를 풀도록 하는 자연스러운 질문임.

지시문으로 구성된 데이터셋으로 fine-tuning을 하는 Instruction tuning을 사용하면 다양한 작업에서의 Zero-shot 성능이 크게 향상됨을 발견했다고 함.
137B의 pre-trained 모델을 가져와 Instruction tuning을 수행한 모델을 FLAN이라 부르며, GPT-3의 Zero-shot 성능을 능가했다고 함.

뒤에 알게된 사실인데, 여기서의 tunning은 Instruct GPT의 SFT처럼 assistant형태의 자연스러운 응답을 생성하도록 하는게 아니고 전통적인 다양한 NLP task를 한 모델이 다 할 수 있도록  tunning하는것이라고 함.

## 1. Introduction

![논문 Figure 2: pretrain-finetune, prompting, instruction tuning 세 방식 비교](/assets/img/ai_paper_reviews/FLAN/flan-fig3.png)

GPT-3가 Few-shot은 상당히 잘하는데 반해, Zero-shot성능은 썩 좋지 못하다는점에 집중함.
아니 Few-shot 그냥 하면 되지 뭐가 그리 어렵다고… 생각했는데 좀 더 생각해보니 사용자가 쓸때는 정말 불편하기도 하고, 컨텍스트도 많이 낭비됨.
그래서 자기들은 다양한 task의 Instruction을 fine-tuning함.
그렇게 만들어진 모델이 FLAN이고, 25개의 벤치마크중 20개에서 GPT-3의 Zero-shot을 능가했고, 6개에서는 Few-shot성능도 능가했다고 함.

## 2. FLAN: Instruction Tuning Improves Zero-Shot Learning

instruction tuning의 동기는 언어 모델이 NLP 지시문(Instructions)에 응답하는 능력을 향상시키는 데 있다 함.
아니, GPT-3도 few-shot 줄때 지시문이랑 같이 줬는데? 뭐가 다르지… 했었는데, 그건 추론할때 프롬프트를 주는거고 instuction tuning은 그냥 fine-tuning단계에서 instruction을 같이 넣고 훈련하는거임.

그래서 Options : 하고 가능한 선지들을 넣어서 경우를 좁혀줘야 공정하다고 함.

## 4. Ablation studies & Further analysis

### 4.1 Number of instruction tuning clusters

![논문 Figure 6: instruction tuning에 쓴 task 클러스터 수를 늘릴수록 held-out 클러스터의 zero-shot 성능이 향상](/assets/img/ai_paper_reviews/FLAN/flan-fig8.png)

Instruction tuning 할때 task 종류를 늘릴수록 unseen task 성능이 올라가는지 테스트함.
클러스터 종류가 늘면 좋다고 하는데, 사실 그냥 개수가 늘어서 그런지 순수 다양성때문인지 제대로 통제가안됨…
추후 Orca 같은 실험에서 다양성과 개수 둘다 중요하다는게 입증됐다고 함.

**느낀점**<br>
자연어로 된 명령이나 요청을 이해하고 작업을 수행할수 있도록 하는게 Instruction tuning.<br>
기존에는 이해를 잘 못해서 few-shot으로 패턴을 만들어주거나 하는식으로 하면서 원시적으로 패턴을 통한 조작을 했어야했음.<br>
엄밀히 말하면 fine-tuning의 하위개념이고, 일반적으로 쓰는 fine-tuning이랑은 또 다른 개념인데, fine-tuning은 막 downstream task에 맞게 Q→A 식으로 특화되는 식이라면 Instruction tuning은 보편적인 지시를 자연어로 적어주면 보고 이행하는것.

## 0. **Abstract**

이 논문은 Faster R-CNN을 백본으로 segmentation 기능을 추가한 모델인 Mask R-CNN을 소개하는 논문임

<details markdown="1">
<summary><strong>R-CNN → Fast R-CNN → Faster R-CNN 발전과정 요약</strong></summary>

나는 R-CNN만 읽어봤으니 Faster R-CNN이 뭔지부터 보자면, R-CNN → Fast R-CNN → Faster R-CNN순으로 발전했음

![Fast R-CNN 구조: 전체 이미지를 CNN에 한 번 통과시킨 뒤 RoI Pooling으로 영역별 특징을 뽑음](/assets/img/ai_paper_reviews/Mask-R-CNN/mask-r-cnn-fig1.png)

Fast R-CNN은 R-CNN에서 2000개의 제안된 영역을 다 2000번 CNN 돌리는게 엄청 느리다는 문제를 해결한 모델이고, 영역제안은 그대로 하지만 **전체 원본이미지**를 통으로 CNN 특징추출기를 돌려버림<br>
FCN인줄 알았는데, CNN층의 분류기를 다른 특징추출기로 대체한게 아니라 그냥 앞의 특징추출층만 떼서 돌린거라 FCN이라고 하지는 않는듯…<br>
뭐 어쨌든 원본 이미지를 통으로 CNN 특징추출기를 돌려서 feature map을 뽑아내고, 원본 이미지에서 영역 제안한것을 feature map에 mapping해서 2000번 CNN을 돌리는게 아니라 딱 한번만 돌리게 됨<br>
그 후 **완전연결층을 통과하고 두가지 branch로 분기되어 하나는 클래스 분류, 하나는 Bounding box 위치를 보정하는 Bbox regressor**로 간다고 함<br>
제안된 영역인 ROI(Region of interest)를 feature map에 mapping할때 ROI Pool을 사용하게 되는데, RoI의 크기가 각각 다 지멋대로 달라서 후속 신경망인 완전연결층에 넘겨주려면 크기가 고정되어야하기때문에 사용한다고 함. 이때 완전연결층(분류기)를 통과할때 실제 ROI 크기에 상관없이 고정 사이즈가 되어야하기때문에 RoI별 특징을 고려하지 못하고 모두 (7x7)같이 일률적인 크기대로 매핑하는 문제점이 생긴다고 함

![Faster R-CNN 구조: selective search 대신 Region Proposal Network로 영역을 제안함](/assets/img/ai_paper_reviews/Mask-R-CNN/mask-r-cnn-fig2.png)

Faster R-CNN은 Fast R-CNN에서 딱 영역제안 방법인 selective search만 손봤음<br>
모델이 영역제안 → CNN 순서로 작동하는데, 기껏 CNN을 효율화해놨더니 고전 CV알고리즘인 selective search는 CPU를 이용하는바람에 느려터져서 저기서 병목이 생겨버렸음<br>
그래서 selective search를 쓰지말고, 영역제안도 RPN (Region Proposal Network)라는 신경망을 사용해서 GPU로 빠르게 돌려버리자는게 이 논문의 핵심이고, 심지어 CNN에서 돌려놓은 feature map을 받아서 사용하기때문에 더욱 효율적임

</details>

여기서, Mask R-CNN은 Faster R-CNN의 branch구조를 계승하여 세번째 branch로 segmentation map을 예측하는 경로를 추가함

## **1. Introduction**

![Mask R-CNN 프레임워크: RoIAlign 뒤에 class·box 분기와 mask 분기가 병렬로 붙음](/assets/img/ai_paper_reviews/Mask-R-CNN/mask-r-cnn-fig3.png)

Mask R-CNN의 대략적인 구조는 이렇고, 그림에 좀 헷갈리게 적혀있는데 “class box”가 아니라 “class”, “box”임… 기존의 Faster R-CNN에서 Classifier와 Bbox regressor 맞음

**첫째로 가장 큰 기여는 성공적인 mask branch 경로를 추가한것임**
근데 여기서 mask(segmentation map)을 예측하는 branch만 만들기만 하면 되는게 아니었다고 함
기존의 Faster R-CNN의 경우는 예를들면 막 원본이미지를 1/16해서 매핑된 위치가 6.25면 그냥 반올림으로 6 이런식으로 조악하게 양자화해서 ROI Pooling에서 정확한 위치정보가 손실되어버렸음…
그래서 바로 쓰지는 못하고, RoIAlign이라는 조악한 양자화를 해결한 연산층으로 대체했고, 그렇게했더니 masking 정확도가 10~50% 올랐다고 함

**두번째 기여는 mask 예측과 class 예측을 분리시켜야한다는것을 찾아낸것임.**
classifier랑 mask predictor는 이미 분기되어있는데 무슨소리지? 했는데, 그말이 아니라 mask predictor 내에서 일어나는 현상에 대한 이야기였음

거기서 제일 높은 확률의 클래스를 해당 픽셀의 클래스로 인정하는 Winner takes all 방식을 사용했는데, 이렇게 하면 어떤 픽셀이 여러가지 속성을 가지고있을때 나머지정보가 소실되는 문제가 있고, 손과 라켓이 겹친부분은 라켓이 선택되면 손이라는 정보가 소실되어 해당 구역이나 경계면이 라켓에 파먹힌듯이 부자연스럽게 표시되는등의 문제가 있었다고 함.

그래서 하나의 픽셀을 두고 한 클래스의 값이 높아지면 다른 클래스는 낮아지는 경쟁적 softmax 방식이 아니라, One vs All 방식의 이진분류기를 여러개 두고 독립적으로 mask를 찾도록 했음.

첫번째는 Segment Proposal 기반 방식임
Segment Proposal은 객체가 있는 위치를 mask로 예측하는 방식으로, 원본 이미지가 (H,W) 크기라고 할때 출력은 N개의 instance 후보들의 피쳐맵이 나와서 (H,W,N)이 됨
Segment Proposal 기반 방식은 먼저 원본 이미지에서 먼저 segmentation을 하고, 걔네들을 Fast R-CNN으로 분류하는 접근법을 사용함.
즉 segmentation이 분류에 앞서는 segmentation first 접근법을 사용하지만, 느리고 정확도가 떨어졌다고 함
당시로서는 FCIS가 이쪽 방식의 최신모델이었는데, segment를 중심으로 거의 동시에 분류도 진행하는 모델이었지만 위의 사진처럼 객체가 겹치는부분에서 이상한 경계를 생성하는 구조적인 문제가 있었다고 함

두번째는 Semantic segmentation 기반방식임
Semantic segmentation은 각 픽셀이 어떤 semantic 클래스에 속할지 출력하는 방식으로, (H,W)크기의 원본 이미지를 넣고 그러면 K개의 클래스별 피쳐맵이 나와서 (H,W,K)크기가 출력됨
Semantic segmentation 기반방식은 먼저 클래스별로 segmentation을 한 후, 각 클래스에서 다시 instance를 구분해내겠다는 방법론이라고 함

저자는 저 기존의 두 방법을 segmentation first 방법론으로 규정하고, 자신들의 Mask R-CNN은 instance first 접근법을 취한다는 점에서 차별된다고 주장했음.
근데 좀 논리에 어폐가있는것같은게, segmentation을 통해서 instance를 구분해낼수도 있는건데 저런식으로 말하면 안되고 차라리 bounding box first 접근법이라고 말 해야 같은 레벨의 비교가 된다고 생각함

그리고 저 bounding box first 접근법은 Faster R-CNN의 RPN을 쓰는걸가지고 저렇게 이름붙인건데, 그럼 기존의 방법론들도 Faster R-CNN의 RPN 쓰면 되잖아? 했지만 걔네들은 segmentation을 먼저 하기때문에 저 object detection 방법론의 bounding box방식이랑 배타적이라 적용이 안됨

## **3. Mask R-CNN**

<figure style="width:100%; margin:0 auto;">
  <img src="/assets/img/ai_paper_reviews/Mask-R-CNN/mask-r-cnn-fig10.png" alt="ResNet 백본, RPN, RoIAlign, Box·Class·Mask 분기로 이어지는 Mask R-CNN 구조도" style="width:100%;">
  <figcaption style="text-align:center; font-size:0.85em; color:gray;">
    위의 Fig 1에서는 RPN 사용하는부분이 잘 표현되어있지 않았는데, 논문 공식 architecture 사진은 아니지만 이 사진이 훨씬 보기 편하고 잘 설명한것같음
  </figcaption>
</figure>

다시한번 구조를 보면서 설명하면, 원본 이미지에서 RPN으로 제안된 영역 RoI(Region of Interest)을 병렬로 분류하고 위치보정하는 개념은 동일하고, 대신 RoI에 대해 클래스별 mask를 예측하는 부분이 추가됨
한 RoI에 대해 (K,m,m) 크기의 텐서맵을 출력함

그럼 K개의 클래스에 대해 mask를 예측하니까 semantic segmentation 아냐? 했는데, semantic segmentation은 전체 이미지를 통으로 mask 예측을 하기도 했고, 픽셀에 클래스별로 경쟁도 있었음.
mask R-CNN은 그렇게 하지 않고 RoI 박스에 대해서 mask 예측을 하고, 클래스별 경쟁도 없음.

$$
L=L_{cls}+L_{box}+L_{mask}
$$

손실함수는 이렇게 정의되고, classification, box regression 손실은 Fast R-CNN에서와 동일함
 $$L_{mask}$$가 새로 생긴 손실함수인데, Binary cross entropy를 사용함

**기존 방식: 이미지의 픽셀이 target.
K개의 mask prediction 채널들을 softmax로 합치고 Categorical cross entropy로 Loss 계산**

<div markdown="1" style="margin-left:1.6em;">

$$
L_{pixel}=-\sum_{k=1}^K y_{k} \log(p_{k}) ,\:\:\: \mathbf{given} \:\:p_k=\frac{e^{z_k}}{e^{z_1}+e^{z_2}+...+e^{z_K}}=\frac{e^{z_k}}{\sum_{i=1}^K e^{z_i}} 
$$

(여기서 $$y_k$$는 정답여부, $$p_k$$는 예측한 확률)

어떤 한 픽셀에 대해서 손실을 구할때 이렇게 구했기때문에 어떤 클래스의 확률이 올라가면 다른 클래스 확률이 낮아지는 경쟁관계가 발생함<br>
테니스 라켓을 잡은 손처럼 픽셀이 두개의 instance가 겹쳐있는 경우 대응이 잘 안됨

</div>

**개선 방식: 각 RoI가 target.
각 RoI를 따로따로 sigmoid + Binary cross entropy로 Loss 계산**

<div markdown="1" style="margin-left:1.6em;">

$$
L_{RoI,pixel}=-[y \log(p)+(1-y) \log(1-p)] ,\:\:\: \mathbf{given}\:\: p=\frac{1}{1+e^{-z}}
$$

(여기서 $$y$$는 정답여부, $$p$$는 예측한 확률)

어떤 RoI의 픽셀에 대해서 손실을 구할때 전처럼 픽셀단위 소프트맥스를 사용하지 않았어서 어떤 클래스의 확률이 올라가도 다른 클래스 확률에 영향없음<br>
테니스 라켓을 잡은 손처럼 픽셀이 두개의 instance가 겹쳐있는 경우에도 손 RoI도 안죽고 라켓 RoI도 안죽음

</div>

mask prediction을 하는 신경망 구조로는, 완전연결층을 사용하면 입력을 억지로 벡터로 쭉 펼치면서 모든 공간정보가 파괴되기때문에 pixel-to-pixel로 공간정보 보존이 가능한 FCN을 사용해야한다고 주장함

또, 저자들은 RoIAllign이라는 방법론을 도입했는데, 기존의 RoIPooling보다 훨씬 정교한 방법임
분류를 수행할때는 양자화때문에 발생하는 작은 불일치가 크게 문제가 되지 않지만, mask 위치를 픽셀단위로 세밀하게 예측할때는 저게 큰 문제가 되었다고 함.

| 값 계산방식 | 샘플링포인트들을 찍고 샘플링포인트들도 보간법으로 계산 | Bin 안에서 제일 큰 값 max pooling.샘플링포인트 개념 없음 |

위의 그림에서 점선격자가 feature map, 실선이 RPN에서 제안한 원래 RoI라고 한다면, 기존에는 실수형태의 좌표로 나온 RoI를 반올림하여 정수 격자에 맞춰버렸음.
그리고 내부구역으로 분할할때도 구역 크기 자체를 정수로 반올림해서 추가 정보손실이 발생했었음.
그래서 RoIAlign에서는 RoI 좌표를 실수값 그대로 사용하고, 내부구역 크기도 반올림없이 그대로 사용했음.
추가적으로 내부구역 내에 일정 수의 샘플링 포인트들을 설정하고, 원래 피쳐맵의 정수값에서 Bilinear Interpolation을 통해 최대한 정보를 보존함

또한 네트워크를 설명하면서 백본과 헤드로는 어떠한 아키텍처를 사용했는지 언급함
Object detection 분야에서는 특징 추출기를 Backbone이라고 부르고, 그걸로 classification이나 Bbox regression이나 masking하는 신경망을 Head라고 부른다고 함
자기들의 방법론이 일반적이라는걸 주장하기 위해서 Backbone에서는 여러 버전의 ResNet과 FPN이라는 네트워크를 사용해보았다고 함

### **4.2. Ablation Experiments**

Mask R-CNN에서 도입한 여러 방법들의 효과를 알아보기 위해 ablation study들을 진행함

Backbone architecture : 실험을 진행했을때 네트워크가 깊어질수록 성능이 올라갔다고 함

**Multinomial vs. Independent Masks** : 3장에서 실컷 다뤘었던 이 논문의 핵심 기여인 경쟁없이 instance를 예측하게 하는 방법(softmax + Categorical cross entropy VS sigmoid + Binary cross entropy)의 효과를 실험적으로 증명함
저자들의 주장대로, 성능차이가 상당히 크게나는것을 확인할 수 있음

**Class-Specific vs. Class-Agnostic Masks** : 기본 Mask R-CNN은 mask 예측하는 네트워크가 클래스 개수 K개만큼 필터를 가지고 있어서 (K,m,m) 이렇게 클래스 각각에 대한 별도의 마스크를 출력하는데, 이걸 클래스 각각에 대한 별도의 마스크를 출력하는 방식이 아니라 그냥 필터 하나가지고 모든 클래스의 마스크를 출력하는 방식을 테스트해봄.
이걸 왜 했냐면 저자들이 기존방법들과 달리 classification과 segmentation을 병렬로 분리했는데, “classification 관련 정보 없이 segmentation 하면 안좋아지는거 아님?” 이라는 의문을 테스트해보기 위함인듯
그래서 비교해보니까 실제로 점수차이가 거의 안났다고 함
이걸 통해 classification과 segmentation를 구조적으로 분리해도 된다는 정당성을 얻은듯

**RoIAlign** : 이것또한 정말 중요한 실험인데, 기존의 조악한 RoIPooling에 비해 RoIAlign이 얼마나 효과적인지 실험적으로 입증했음.
표를 보면 알수있듯이 RoIAlign이 더 성능이 잘 나오는걸 확인할 수 있고, (c)→(d)로 네트워크 깊이를 더 깊게 해 유효 스트라이드가 더 크게 하니까 성능차이가 더 두드러지는걸 확인할 수 있었음
